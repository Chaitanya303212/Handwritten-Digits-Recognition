# Handwritten Digits Recognition

## Project Overview
This project focuses on recognizing handwritten digits using machine learning and image classification techniques.

## Objective
To develop a model that can identify handwritten numerical digits from image data.

## Project Workflow
- Dataset loading
- Exploratory data analysis
- Image preprocessing
- Model development
- Model training and testing
- Performance evaluation

## Technologies Used
- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
